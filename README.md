# Shareefunnisa Syed | Portfolio Website

My personal portfolio website, built from scratch with plain HTML, CSS, and JavaScript and hosted on GitHub Pages.

**Live site:** [shareefunnisa-syed.github.io](https://shareefunnisa-syed.github.io)

## About
A single-page portfolio that presents my skills, experience, projects, internships, and certifications as an IT Associate and aspiring Data Analyst.

## Sections
- **Home:** introduction and a quick overview of my tools
- **About:** Skills, Experience, and Education (switchable tabs)
- **Projects:** office projects and academic/personal projects, with GitHub links
- **Internships:** Salesforce Developer and Web Development internships
- **Certifications:** with links to view each certificate
- **Contact:** email, LinkedIn, GitHub, resume download, and a contact form

## Features
- Fully responsive layout for mobile, tablet, and desktop
- Automatic light and dark mode, following the device setting
- Sticky navigation bar with smooth scrolling
- Accessible tabs (ARIA roles) and visible keyboard focus
- Animated bar chart in the hero section, with reduced-motion support
- Contact form that opens the visitor's email app with the message filled in
- No frameworks or libraries, just one `index.html` file

## Tech Stack
| Technology | Use |
|-----------|-----|
| HTML5 | Page structure |
| CSS3 | Styling, grid, flexbox, CSS variables, dark mode |
| JavaScript | Tabs and contact form |
